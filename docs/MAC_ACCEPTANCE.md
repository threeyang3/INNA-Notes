# IINA Video Notes：真实 Mac 验收清单

本清单供真实 macOS / IINA 环境执行。**以下条目均为待执行，不代表已经通过。** 自动化模拟播放器、文件故障和前端消息，只验证相应业务逻辑，不能代替播放器、WebKit、色彩、权限和原生文件系统验收。

先准备独立测试输出目录与可重复播放的短片。磁盘满、权限和目录替换只在可丢弃的测试位置执行，不对已有 Vault 或视频原件做破坏性试验。

## 2. 打包与安装

- [ ] 在实现分支执行 `npm test`、`npm run build`、`npm run check`、`npm run package`，保留终端结果。
- [ ] 在 Mac 另运行 `/Applications/IINA.app/Contents/MacOS/iina-plugin pack .`，确认官方 CLI 接受项目结构。
- [ ] 包顶层有 `Info.json`，`entry` 对应 `dist/main.js`，UI 文件齐全，没有额外包一层仓库目录。
- [ ] 用真实 IINA 打开最终 `.iinaplgz`，安装、启用并新建播放器成功。
- [ ] 权限只涉及文件系统、系统提示和 OSD，没有通用网络权限。
- [ ] 测试开发 `iina-plugin link .` / `unlink .`，构建后重载或重新打开播放器能看到修改。
- [ ] 如果实现仍在 PR，必须使用该分支的包；旧 `main` 安装成功不算本次实现通过。
- [ ] 日志没有缺失 API、Node/浏览器全局未定义错误或重复初始化异常。

## 3. 必须先通过的最小闭环

1. 在 IINA 打开本地视频，选一个画面清晰可辨的片段。
2. 将输出设为测试 Vault 内的 `Video Captures/IINA`。
3. 播放中按 ⌘⇧N，立即输入中文或日文笔记。
4. 确认捕获位置固定；让视频继续播放后保存。
5. 在 Obsidian 打开新 Markdown。

逐项确认：

- [ ] 正文与输入完全一致，包括换行、引号、Markdown 和非 ASCII 字符。
- [ ] PNG 正常显示，来自正确视频；无播放器控制栏、桌面和其他窗口。
- [ ] 协议为 `media-video-capture/v1`，ID 与 Markdown/图片文件名一致。
- [ ] `captured_at` 是触发时间，而非稍后的保存时间。
- [ ] `video_position_ms` 为触发时固定的非负整数毫秒，没有跟着播放移动。
- [ ] `video_source_uri` 对应真实本地文件，特殊字符正确。
- [ ] 重复保存不会产生第二个 ID 的同内容记录。
- [ ] 退出 Obsidian 后再采集一次，保存仍独立成功。

## 4. 核心功能矩阵

| 编号 | 操作与条件 | 必须观察的结果 | 状态 |
| --- | --- | --- | --- |
| 01 | 本地 MKV、MP4、MOV 正常播放后捕获 | 来源、标题、位置、PNG、正文完整；未知时长省略 | 待验收 |
| 02 | 播放中/原本暂停时捕获，自动暂停先关后开 | 默认不改变播放；原本暂停不擅自恢复；暂停字段反映触发状态 | 待验收 |
| 03 | 无文件、加载/切换中、音频或无视频轨时触发 | 明确提示，不生成伪造来源或 0 秒成功记录 | 待验收 |
| 04 | A/B 播放器交替捕获，输入不同文字 | 文件、位置、截图、草稿隔离；A 的异步结果不覆盖 B 或抢焦点 | 待验收 |
| 05 | 固定画面分别含/不含字幕，测试内嵌和外部 ASS/SRT | 模式确实生效，无控制栏；不能将旧截图当成新模式 | 待验收 |
| 06 | 受控故障使图片发布成功、Markdown 失败 | 不报告成功；保留完整图片/草稿；原 ID 重试，无引用半成品的 Markdown | 待验收 |
| 07 | Markdown 发布前截图失败、超时、内容无效 | 保留时间和文字；仅明确关闭截图选项后可保存文字 | 待验收 |
| 08 | 失败后关窗、重开、退出/重启 IINA、恢复草稿 | 原正文、时间、ID、截图可恢复；重启不为旧位置生成新画面 | 待验收 |
| 09 | 连按快捷键、双击保存、保存中 ⌘↵ | 聚焦当前草稿而不改来源；只有一次最终导出 | 待验收 |
| 10 | 中文、日文、空格、`#`、`?`、引号、字面 `%20`、反引号、`${...}` 文件名/目录 | 路径保真；无脚本执行、模板错误或 YAML 注入 | 待验收 |
| 11 | 只读/权限撤销、测试卷满、目录变化、已有同名文件 | 明确失败并保护草稿；无覆盖/迁移；绑定计划显示原目标 | 待验收 |
| 12 | Obsidian 阅读/源码模式；整个输出目录复制到另一个测试 Vault | 正文和相对图片引用可读；仅复制 Markdown 时识别缺图 | 待验收 |
| 13 | 重新加载 WebView/插件后恢复并保存 | 无重复 handler、捕获或保存；异步状态不清空输入 | 待验收 |
| 14 | 面板开着时播放、seek、切文件、关闭播放器 | 不自动重载或撤销用户操作；不把新画面挂到旧位置；定时器停止 | 待验收 |
| 15 | 保存后禁用/卸载，再移动/删除测试视频 | Markdown/PNG 可独立阅读；核对默认数据目录是否保留 | 待验收 |
| 16 | 无 Obsidian、无 MediaCore，使用默认目录 | 捕获、草稿恢复、保存、Finder 查看全部独立可用 | 待验收 |

## 5. 截图画质与时间位置

- [ ] 用烧录时间码或易识别帧号的片段对比 PNG 与毫秒位置，分别记录播放中、暂停时偏差；毫秒字段不代表逐帧保证。
- [ ] 测试 1080p、4K 和实际使用的更高分辨率，原 PNG 不是 960 像素预览副本。
- [ ] 测试 SDR、HDR10 和实际使用的 HDR/Dolby Vision，检查亮度、颜色、色调映射、暗部与高光。
- [ ] 比较原 PNG、笔记预览和 Obsidian 显示，记录差异，不能用预览代替原图验收。
- [ ] 检查字幕描边、透明度、ASS 字体/特效、外部字体、顶部/底部字幕，含/不含模式正确。
- [ ] 测试旋转信息、非方形像素、黑边和裁剪设置，记录图片方向与尺寸。
- [ ] 大图生成时继续播放、输入，观察卡顿、输入延迟和内存，实测原生异步行为。
- [ ] 超过 128 MiB 上限有明确反馈；预览失败不会损坏原 PNG。

画面或颜色不一致必须记录，不能凭“PNG 已存在”或模拟测试通过判定画质通过。

## 6. 草稿、重试与暂停所有权

- [ ] 输入后立即用原生红色按钮关窗，再打开草稿核对最后内容；测试中文/日文输入法组合输入、多行粘贴和长度上限。
- [ ] 同一窗口连续快捷键返回当前稿；保留并关闭后才生成新 ID 和新时间。
- [ ] 同文件暂停于原位置 ±50 ms 可重试；偏离则拒绝。同名、不同路径视频同样拒绝。
- [ ] 原文件关闭再打开，即使路径与位置相同，也不能当成同一次加载的截图重试。
- [ ] 已有截图时保存不要求视频继续存在；重启后同样可保存已有截图和正文。
- [ ] 自动暂停关闭：捕获、保存、取消和失败均不改变原状态。
- [ ] 自动暂停开启且原先播放：主动暂停；没有其他操作时，明确保存/关闭按设计恢复。
- [ ] 原先暂停：保存/关闭后仍暂停。
- [ ] 期间手动播放、再次暂停、拖动进度、seek、切文件；保存/关闭不覆盖用户意图。
- [ ] 设置、草稿视图、原生关闭、关闭播放器、禁用插件，不留下后台观察任务。
- [ ] 多窗口尝试恢复同一草稿，旧窗口不能无提示覆盖新归属；冲突时提示复制当前文字。

## 7. 文件与隐私

- [ ] 默认导出在 `@data/exports/IINA`，不是 `@tmp` 或插件包内。
- [ ] 所选目录直接作为根，不重复添加 `IINA`。
- [ ] 原视频内容、大小、修改时间不变，没有被复制到 Vault。
- [ ] 同名现有 Markdown/PNG 内容不同时拒绝覆盖，保留用户编辑。
- [ ] 测试 APFS/HFS+ 同卷发布；另用可丢弃 exFAT/不支持硬链接挂载目录确认失败，不静默降级。
- [ ] 已建立计划且尚未发布 Markdown 的失败草稿：选择新目录后先确认目标仍显示旧目录；明确点击「改存当前目录」才改变目标，随后保存仍使用原 ID、捕获时间、正文和截图。
- [ ] 改存前旧目录中的图片和暂存文件不被搬迁或删除；改存本身不会自动发布笔记。
- [ ] 旧目录不可读，或者已有该 ID 的 Markdown 时，改存必须拒绝，新目录不产生重复 Markdown；恢复原目录权限或检查原导出后再处理。
- [ ] 测试输出子目录放置符号链接或替换目录，拒绝越界写入。
- [ ] 受控测试卷权限不足/空间耗尽时，确认官方 `utils.exec` 调用系统 `/bin/cp -n` 的失败退出码会转化为保存错误，草稿和原截图保留；不把复制失败当作成功。若 IINA 崩溃，作为阻断问题记录，不算通过。
- [ ] 原生二进制复制后，64 KiB 分块读取比对和 PNG 结构校验能拒绝不完整或不同的目标文件；高分辨率图片的实际耗时、播放和输入响应仍须实测。
- [ ] 图片发布、Markdown 未发布时，不将 `.pending` 当笔记；恢复后原 ID 唯一。
- [ ] 路径开启时正确 URI 可回指实际文件；关闭时省略该字段并出现 `video_source_redacted: true`。
- [ ] 隐私关闭仍可在本地草稿看到真实路径，明确其不负责清除草稿。
- [ ] 暂存清理失败仅留受限临时文件，不递归删除其他目录和记录。
- [ ] 停用插件后无后台进程，普通编辑器/图片查看器仍可阅读导出。

## 8. UI、键位与独立使用

- [ ] 亮/暗主题、常用尺寸、高 DPI 正常；长标题/路径不挤掉保存按钮。
- [ ] 触发后立即输入；异步截图不抢其他窗口焦点，不重置正文和选区。
- [ ] ⌘⇧N 无键位冲突；冲突时可修改，菜单始终可用。
- [ ] ⌘↵ 保存、Esc 返回/保留草稿关闭；输入法组合期间回车不误保存。
- [ ] Tab/Shift+Tab 可到达表单与按钮，状态可读；三种保存方式均可完成。
- [ ] 目录选择可取消，界面仍可使用；错误后文字与截图引用仍在。
- [ ] 设置变化不清空当前稿；失败稿绑定旧目录时显示真实目标。
- [ ] 不运行 Obsidian、不安装 MediaCore，默认目录、设置、草稿和文件查看全部可用。
